Route B status:

- Invalid / not yet runnable as a benchmark sample.
- Direct Claude Code inside the same container can answer a trivial prompt
  (`Say OK only`) through Seed Agent Plan.
- For the actual coding prompt, Claude Code exits with 137 before producing a
  usable assistant/tool trajectory. This reproduces both inside Harbor and with
  a direct `docker run` using the same binary, endpoint, model, and proxy.
- Switching from `stream-json` to `json` output did not fix the 137 exit.

## Current Conclusion

The faithful upstream-shaped route is now implemented as Route A, and one valid
task-level canary shows no improvement on `cancel-async-tasks`: reward remains
`0`, failing the queued cancellation cleanup test.

The Claude Code adaptation route is not ready for comparison because
`ClaudeCode + kimi-k2.6` is unstable for this coding prompt in the container
runtime. Do not count Route B samples until the CLI/runtime 137 issue is fixed.
